# RB SELF DRIVE — Simple Final

Premium simple self-drive booking website for RB SELF DRIVE, Porbandar.

## Included
- Real car photos
- Liquid Glass animations
- Car details popup
- Availability checker
- Simple booking form: Name, Car, Mobile, Pickup Date, Return Date
- WhatsApp booking
- Booking request confirmation animation
- Dark/Light mode
- Reviews
- FAQ
- Google Maps
- Responsive mobile + PC layout

## Not included
- No online payment
- No UPI QR
- No payment section
- No pickup/drop location field
- No admin dashboard
- No coupon/KYC/invoice/analytics

## Run
```bash
npm install
npm start
```
Open http://localhost:3000
